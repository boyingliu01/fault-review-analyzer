# 故障聚类分析系统 V2 - 原子任务拆分

## 任务总览

基于设计文档，将系统实现拆分为以下原子任务，按优先级和依赖关系排序。

---

## P0 - 核心功能（必须实现）

### 任务1: Chroma向量数据库集成
**任务ID**: T1  
**优先级**: P0  
**依赖**: 无  
**预估工时**: 4小时

**输入**:
- 现有项目结构
- Chroma库文档

**输出**:
- `src/storage/chroma_manager.py` - Chroma管理器类
- 支持创建集合、添加向量、查询向量、更新元数据
- 单元测试

**实现约束**:
- 使用Chroma的PersistentClient实现持久化
- 集合名称默认为"fault_embeddings"
- 元数据包含task_id, title, priority, create_time等字段
- 支持批量插入

**验收标准**:
- [ ] 可以创建集合并添加向量
- [ ] 可以查询所有向量
- [ ] 可以按ID查询特定向量
- [ ] 可以更新元数据
- [ ] 单元测试覆盖率≥80%

---

### 任务2: 分离向量化阶段和聚类阶段
**任务ID**: T2  
**优先级**: P0  
**依赖**: T1  
**预估工时**: 6小时

**输入**:
- 现有`analyze_faults_v2.py`
- T1完成的ChromaManager

**输出**:
- `scripts/phase1_prepare.py` - 阶段一脚本
- `scripts/phase2_analyze.py` - 阶段二脚本
- 修改后的分析流程

**实现约束**:
- 阶段一：提取数据 → LLM分析 → 向量化 → 存储到Chroma
- 阶段二：从Chroma加载 → 聚类分析 → 生成报告
- 阶段一只需执行一次，阶段二可重复执行
- 支持增量更新（新增故障单）

**验收标准**:
- [ ] 阶段一可以独立运行并保存数据到Chroma
- [ ] 阶段二可以从Chroma读取数据并执行聚类
- [ ] 阶段二可以多次运行，使用不同参数
- [ ] 支持向已存在的集合中添加新故障单

### 任务4: HDBSCAN参数可调支持
**任务ID**: T4  
**优先级**: P0  
**依赖**: T2  
**预估工时**: 4小时

**输入**:
- 现有`ClusterAnalyzer`类
- HDBSCAN文档

**输出**:
- 增强的`ClusterAnalyzer`类
- 支持参数：algorithm, min_cluster_size, min_samples, metric
- 聚类质量评估（轮廓系数）

**实现约束**:
- 支持算法切换：hdbscan, hierarchical, kmeans
- 支持距离度量：cosine, euclidean
- 提供聚类统计信息
- 计算轮廓系数评估质量

**验收标准**:
- [ ] 可以通过参数切换聚类算法
- [ ] 可以调整HDBSCAN的min_cluster_size和min_samples
- [ ] 返回聚类数量、噪声点数量、轮廓系数
- [ ] 支持余弦相似度和欧氏距离
