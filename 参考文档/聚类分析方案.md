## 3. 分析步骤详细说明

### 3.1 数据准备

```python
# 1. 读取数据
df = pd.read_excel('国际中心2025年关闭的已集中复盘的泄露缺陷单.xlsx')

# 2. 数据清洗
df = df.dropna(subset=['引入环节', '泄露原因'])

# 3. 特征编码
from sklearn.preprocessing import LabelEncoder
le = LabelEncoder()
for col in ['引入环节', '泄露原因', '引入原因', '泄漏根因类型']:
    df[col + '_encoded'] = le.fit_transform(df[col].astype(str))
```

### 3.2 聚类执行

```python
# 1. 选择特征
features = ['引入环节_encoded', '泄露原因_encoded', '引入原因_encoded', '泄漏根因类型_encoded']

# 2. K-means聚类
from sklearn.cluster import KMeans
kmeans = KMeans(n_clusters=3, random_state=42)
df['cluster'] = kmeans.fit_predict(df[features])
```

### 3.3 结果分析

```python
# 1. 全局Top3分析
from collections import Counter

print("引入环节Top3:")
Counter(df['引入环节']).most_common(3)

print("泄露原因Top3:")
Counter(df['泄露原因']).most_common(3)

# 2. 聚类分析
for i in range(3):
    cluster_data = df[df['cluster'] == i]
    print(f"\n聚类 {i+1}:")
    print(f"样本数量: {len(cluster_data)}")
    print("引入环节Top3:", Counter(cluster_data['引入环节']).most_common(3))
    print("泄露原因Top3:", Counter(cluster_data['泄露原因']).most_common(3))
```
