# API 变更日志

## 0.1.0 (2026-03-31)

### 新增功能

- 新增健康检查接口 (`GET /health`)
- 新增单个任务分析接口 (`POST /analyze`)
- 新增批量分析接口 (`POST /analyze/batch`)
- 新增聚类列表查询接口 (`GET /clusters`)
- 新增聚类详情查询接口 (`GET /clusters/{cluster_id}`)
- 新增报告获取接口 (`GET /reports/{task_id}`)
- 新增反馈管理接口 (`POST /feedback`)

### 接口详情

#### 健康检查接口
- **路径**: `/health`
- **方法**: GET
- **描述**: 检查 API 服务器的健康状态
- **认证**: 不需要

#### 任务分析接口
- **路径**: `/analyze`
- **方法**: POST
- **描述**: 分析指定任务的故障信息
- **认证**: 需要
- **参数**:
  - `task_id`: 任务编号（必填）
  - `options`: 分析选项（可选）

#### 批量分析接口
- **路径**: `/analyze/batch`
- **方法**: POST
- **描述**: 批量分析多个任务的故障信息
- **认证**: 需要
- **参数**:
  - `task_ids`: 任务编号列表（必填）
  - `options`: 分析选项（可选）

#### 聚类查询接口
- **路径**: `/clusters`
- **方法**: GET
- **描述**: 获取所有故障聚类信息
- **认证**: 需要

#### 聚类详情接口
- **路径**: `/clusters/{cluster_id}`
- **方法**: GET
- **描述**: 获取指定聚类的详细信息
- **认证**: 需要
- **参数**:
  - `cluster_id`: 聚类编号（必填）

#### 报告获取接口
- **路径**: `/reports/{task_id}`
- **方法**: GET
- **描述**: 获取指定任务的分析报告
- **认证**: 需要
- **参数**:
  - `task_id`: 任务编号（必填）
  - `format`: 报告格式（可选，支持 html/markdown/json）

#### 反馈管理接口
- **路径**: `/feedback`
- **方法**: POST
- **描述**: 提交对分析结果的反馈
- **认证**: 需要
- **参数**:
  - `task_id`: 任务编号（必填）
  - `feedback_type`: 反馈类型（必填）
  - `content`: 反馈内容（必填）
  - `metadata`: 反馈元数据（可选）

### 认证和授权

- 新增 Token 认证机制
- 仅支持通过 `X-API-Token` HTTP Header 传递 Token
- 新增速率限制中间件（默认每分钟 60 次请求）
- 默认拒绝未认证请求，仅支持通过 `API_ALLOW_UNAUTHENTICATED=true` 显式启用本地开发免认证模式

### 错误处理

- 统一错误响应格式
- 新增常见错误状态码和错误类型
- 提供详细的错误信息和调试信息

### 文档和示例

- 新增 API 文档（`docs/API.md`）
- 新增使用示例（Python requests 库和 cURL）
- 新增错误码说明

### 开发和测试

- 新增 API 服务器测试（`tests/api/test_server.py`）
- 新增中间件测试（`tests/api/test_middleware.py`）

## 升级指南

### 从 0.0.1 到 0.1.0

#### 接口变更

1. **任务分析接口**
   - 原接口: `/api/v1/task/analyze`
   - 新接口: `/analyze`
   - 参数调整: 新增 `options` 字段

2. **聚类查询接口**
   - 原接口: `/api/v1/clusters/list`
   - 新接口: `/clusters`

3. **报告获取接口**
   - 原接口: `/api/v1/report/get`
   - 新接口: `/reports/{task_id}`

#### 认证变更

- 原认证方式: Bearer Token
- 新认证方式: `X-API-Token` HTTP Header

#### 响应格式变更

- 统一响应格式
- 新增错误响应格式
- 调整成功响应结构
