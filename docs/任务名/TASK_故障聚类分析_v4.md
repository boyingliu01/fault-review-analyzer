#### T1a: PDF规范解析提取（独立任务）
**预估工时**: 12小时  
**依赖**: 无

## 风险与应对

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 规范知识库不完整 | 高 | 提供示例规范，支持人工补充 |
| 违规模测准确率低 | 高 | 人工审核检测结果，持续优化Prompt |
| 根因可落地性验证困难 | 中 | 结合规则引擎和LLM，双重验证 |
| 多模态向量化成本高 | 中 | 优化API调用，缓存向量结果 |
| 代码变更分析复杂度高 | 中 | 分步实现，先支持基本diff分析 |
| LLM成本过高 | 中 | 优化Prompt，减少调用次数 |
| 改进措施落地困难 | 中 | 明确验收标准，提供具体可执行措施 |
