## 简介
本手册面向使用"fault-analyzer"命令行工具的用户，覆盖数据获取、分析执行、报告生成、配置管理、缓存管理等全部功能。文档提供从简单任务到复杂批处理的完整工作流示例，说明配置文件与环境变量用法，并给出调试、日志查看、常见问题排查以及与其他工具集成和自动化部署的最佳实践。

**更新** CacheManager现在支持上下文管理器模式，所有CLI命令都使用with语句进行资源管理，确保数据库连接的正确关闭和资源释放。

## 核心组件
- CLI 主程序：注册子命令并提供版本信息输出。
- fetch：从研发管理系统拉取任务详情，支持单条与批量，带缓存与进度展示，使用上下文管理器模式管理缓存资源。
- analyze：对单个或批量任务进行分析（标签、根因、规范检查），可选聚类，支持报告输出，通过with语句确保缓存资源正确释放。
- report：基于缓存结果生成单任务、聚类或批量报告，支持多种格式，使用上下文管理器安全访问缓存数据。
- config：查看、设置、显示配置文件路径。
- cache：列出、清理、统计、过期清理等缓存操作，**全面采用上下文管理器模式进行资源管理**。
- AnalysisPipeline：编排预处理、LLM 分析、规则检查、报告生成与聚类。
- ReportGenerator：模板渲染与多格式输出（Markdown/HTML/JSON/PDF）。
- ConfigManager：YAML/JSON 配置加载、合并、环境覆盖、类型校验。
- **新增** CacheManager：SQLite缓存管理器，支持上下文管理器协议，自动处理数据库连接的打开和关闭。

**更新** 所有缓存相关操作现在都使用`with CacheManager(...) as cache_manager:`的模式，确保数据库连接在操作完成后自动关闭，避免资源泄漏。

## 性能与扩展建议
- 启用缓存：减少重复网络请求与 LLM 调用，提升吞吐。

- **更新** 利用上下文管理器优化：通过with语句确保缓存资源的及时释放，避免连接泄漏导致的性能问题。

## 故障排除指南
- 常见安装与依赖问题：Python 版本、系统依赖缺失、镜像源切换。
- 配置问题：.env 未加载、配置验证失败、必需项缺失、--config 路径错误。
- API 调用问题：认证失败、超时、接口 404。
- LLM 服务问题：认证失败、超时、模型不存在。
- 嵌入与聚类问题：生成失败、速度慢、结果为空、效果不佳。
- 性能与内存问题：分析慢、启动慢、OOM。
- 数据存储问题：ChromaDB/SQLite 错误、权限问题。

### CacheManager 上下文管理器模式详解
**新增** CacheManager现在实现了Python的上下文管理器协议，支持with语句进行资源管理：

- `__enter__()`：进入上下文时返回自身实例，用于初始化数据库连接
- `__exit__()`：退出上下文时自动调用close()方法，确保数据库连接正确关闭
- 线程安全：内部使用RLock确保多线程环境下的数据安全
- 自动资源清理：无论正常退出还是异常退出，都会确保数据库连接被关闭

使用示例：
```python
# 推荐方式 - 使用上下文管理器
with CacheManager(db_path="./data/cache/cache.db") as cache_manager:
    data = cache_manager.get_task(task_id)
    # 操作完成后自动关闭连接

# 传统方式 - 手动管理（不推荐）
cache_manager = CacheManager(db_path="./data/cache/cache.db")
try:
    data = cache_manager.get_task(task_id)
finally:
    cache_manager.close()
```

**更新** 所有CLI命令现在都推荐使用with语句模式，提供更好的资源管理和错误处理。
